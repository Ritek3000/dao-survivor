# Lizenzen der Klänge

## Mitgelieferte Dateien

Alle Dateien in `sfx/`, `schleifen/` und `musik/` sind **selbst erzeugt**: `tools/audio-erzeugen.py` rechnet sie aus Schwingungen,
Rauschen, Filtern und Hall (Python, numpy). Es stecken keine Aufnahmen, Samples, Klangbibliotheken oder Melodien Dritter darin, und es wurde
nichts aus dem Netz geladen. Rechte Dritter bestehen deshalb nicht.

Die Dateien sind Platzhalter. Sie gehören zum Projekt und stehen unter dem, was Fabian für das Projekt festlegt (das Repository hat noch
keine Lizenzdatei).

## Eigene oder fremde Klänge eintragen

Wer eine Datei austauscht, trägt sie hier ein, damit später klar ist, woher sie stammt und was man damit darf:

| Datei                 | Quelle / Urheber | Lizenz (mit Link) | Änderungen |
| --------------------- | ---------------- | ----------------- | ---------- |
| _(noch keine eigenen)_ |                  |                   |            |

Nur Klänge verwenden, die frei lizenziert sind (etwa CC0 oder CC BY mit Namensnennung) oder die man selbst gemacht hat.
Bei CC BY gehört die geforderte Namensnennung in diese Tabelle.
